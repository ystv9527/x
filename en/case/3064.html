🎨 Chinese Prompt

请使用上传的人物参考图作为严格的身份与服装参考。

请保留参考人物的：
- 脸部身份
- 面部比例
- 眼型
- 鼻子
- 嘴唇
- 肤色
- 发型
- 发色
- 可见发饰
- 整体可识别气质
- 参考图中展示的服装与穿搭风格

不要硬编码参考图中不存在的具体角色特征。
所有身份、发型、配饰、服装、颜色和造型细节，都必须直接根据上传的参考图推断。

请创作一张高质量的混合风格竖版肖像，包含：
1. 一位基于上传参考图的真实感全身人物
2. 一幅画在人物旁边墙面上的、可爱彩色的 2D Q版插画版同一人物

核心概念：
真人在一幅放大的彩色 Q版墙绘旁边摆出可爱的姿势。
真人与墙绘中的 Q版形象做出相似但不完全相同的互动姿势。
Q版插画必须像是同一人物的可爱手绘动漫风墙面艺术，而不是另一位真实人物。
整体氛围要可爱、俏皮、明亮、时髦、讨喜，并适合社交媒体传播。

主风格方向：
这不是黑色涂鸦影子概念。
这是“真实人物 + 彩色可爱 Q版墙绘插画”的概念。
墙面插画应像一幅精致但带手绘感的 2D 动漫/Q版绘画，直接呈现在墙上。

真人部分：
- 真实人像摄影感
- 全身或接近全身构图
- 与上传参考图保持同样可识别的身份
- 服装风格和关键可见细节与参考图一致
- 自然、上镜的姿势
- 可爱、俏皮、略带害羞或坏坏的表情
- 人物需要主动做出一个与墙绘呼应的可爱动作
- 不要站得过于僵硬
- 不要把服装换成无关时装

真人姿势可选：
请选择一种适合与墙绘同框的可爱俏皮姿势：
- 双手靠近脸颊，像可爱小爪子
- 一条腿微微抬起
- 偶像感俏皮姿势
- 害羞但可爱的姿势
- 做一个小爱心手势
- 轻盈弹跳感姿势
- 微微倾身并带甜美微笑
- 双手弯曲靠近脸部的“喵”姿势
- 像轻轻起跳但仍然自然平衡的姿势

姿势应当对真人来说自然，不要夸张或不合身体结构。

Q版墙绘插画：
- 插画必须是同一上传人物的可爱彩色 2D Q版版本
- 插画应直接画在真人旁边的墙面上
- 不是另一位真实人物
- 不是 3D 角色
- 不是黑色影子
- 不是简单火柴人
- 不是随机动漫角色
- 不是无关的其他女孩
- 需要通过发型轮廓、发色、配饰、服装轮廓、配色和整体气质，清楚地像真人本人
- 使用大而有神的眼睛、圆润可爱的脸、小巧身体比例和柔和的动漫上色
- Q版形象应做出比真人更夸张、更可爱的同款姿势
- Q版可以呈现跳跃、摆姿势或轻微漂浮的感觉，作为墙绘的一部分

墙面插画细节：
- 线条干净柔和
- 温暖的粉彩配色
- 可爱的动漫/Q版渲染
- 轻微手绘纹理
- 细腻的柔和阴影
- 表情讨喜且生动
- 与真人相同的服装印象
- 如果参考图中可见，则保留相同发型与配饰线索
- Q版周围有俏皮的动作线
- 可加入小爱心、星星、闪光、软萌涂鸦点缀或小装饰符号

互动关系：
真人与 Q版插画之间必须有明确连接感。
两者应共享同一个姿势概念，但不要完全一致。
真人做的是更自然、真实的可爱姿势。
Q版做的是更夸张、更萌、更动漫化的版本。
整体连接应当一眼就能看懂，像是在个性化墙绘旁拍的一张有趣照片。

构图：
- 竖版 4:5 或 9:16
- 简洁干净的室内墙面
- 真人在画面一侧
- 彩色 Q版墙绘在另一侧
- 两者都要完整或接近完整入镜
- Q版墙绘高度与真人接近，或略大一些
- 两者周围留足负空间
- 墙绘必须完整可见
- 避免裁切真人脚部或 Q版身体

背景：
- 干净的白色、奶油色、浅米色或浅灰色墙面
- 简单地面
- 极简室内或干净房间场景
- 柔和自然光
- 背景整洁
- 不要出现 TikTok 界面、社交媒体界面或文字叠层

光线：
- 柔和自然的棚拍光感
- 明亮、干净、温暖、讨喜
- 真人身下有真实阴影
- 墙绘看起来自然地贴合在墙面上
- 不要硬阴影
- 不要戏剧化暗光

风格质量：
- 真实人像摄影
- 彩色 2D Q版墙绘插画
- 可爱动漫风墙面艺术
- 身份相似度高
- 服装与造型忠实参考上传图片
- 俏皮互动姿势
