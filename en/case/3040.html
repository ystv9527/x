📝 Summary

Organize a Chinese prompt for generating a character reference sheet, with the core focus on keeping the same character’s facial features, hairstyle, proportions, clothing, and expression consistent.

🎨 Chinese Prompt

生成一张高精度“角色设定板”，用于锁定同一角色的统一形象。
基于上传的参考图或以下描述，生成完整角色设定板。所有模块必须是同一个角色，禁止脸型、发型、服装、比例发生任何漂移。
【基础设定】
风格：【写实3D / 动漫 / 半写实 / IP设计】
角色描述：【填写详细描述，或说明已上传参考图】
性别 / 年龄 / 体型：【填写】
风格关键词：【高级感 / 科技感 / 情绪化 / 未来感 等】
背景：纯白或极简浅色
版式：干净、专业、技术型设定板
要求：无水印、无Logo、标签清晰
【必须包含模块】
1. 顶部信息区（名字、身份、年龄、性格关键词3-5个、核心主题描述）
2. 配色系统（6-8个主色块）
3. 主身份展示（最大区域）：正面 + 四分之三侧面 + 侧面 + 背面 + 标准站姿 + 身高比例线
4. 轮廓剪影（正面 + 侧面）
5. 表情系统（8张）：平静、好奇、紧张、惊讶、害怕、悲伤、坚定、放松
6. 微表情（5张）
7. 头部结构（四分之三、侧面、仰视、俯视）
8. 姿态变化（放松、紧张、自信）
9. 情绪特写（胸部以上强情绪近景）
10. 服装细节（发型、材质、配饰、鞋子）
11. 手部动作（放松、紧张、指向、抓握、接触面部）
【一致性要求】
所有模块必须是同一个角色，脸型、发型、身体比例、服装完全一致。
主展示区域必须最大、最清晰，作为统一参照。
请输出完整、专业、结构清晰的角色设定板。

🎨 English Prompt

Generate a high-precision character turnaround sheet to lock a single character’s consistent appearance.
Based on the uploaded reference image or the description below, create a complete character turnaround sheet. All modules must show the same character, with no drift in face shape, hairstyle, clothing, or proportions.
[Basic Settings]
Style: [realistic 3D / anime / semi-realistic / IP design]
Character description: [fill in detailed description, or indicate that a reference image has been uploaded]
Gender / age / body type: [fill in]
Style keywords: [premium / tech / emotional / futuristic, etc.]
Background: pure white or minimal light color
Layout: clean, professional, technical turnaround sheet
Requirements: no watermark, no logo, clear labels
[Required Modules]
1. Top information area (name, identity, age, 3-5 personality keywords, core theme description)
2. Color system (6-8 main color swatches)
3. Main identity display (largest area): front view + three-quarter view + side view + back view + standard standing pose + height proportion line
4. Silhouette (front and side)
5. Expression set (8): calm, curious, nervous, surprised, afraid, sad, determined, relaxed
6. Micro-expressions (5)
7. Head structure (three-quarter, side, low angle, high angle)
8. Pose variations (relaxed, nervous, confident)
9. Emotional close-up (intense expression, chest-up close shot)
10. Clothing details (hair, material, accessories, shoes)
11. Hand actions (relaxed, nervous, pointing, gripping, touching face)
[Consistency Requirements]
All modules must be the same character, with identical face shape, hairstyle, body proportions, and clothing.
The main display area must be the largest and clearest reference.
Please output a complete, professional, and clearly structured character turnaround sheet.
